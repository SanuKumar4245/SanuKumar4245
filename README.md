### 📦 Featured Project

#### 🚆 [Coolio: Railway Porter Booking Platform (Backend)](https://github.com/SanuKumar4245/Coolio)

*A concurrency-safe Spring Boot backend for porter booking, payments, and notifications.*

- **Stack**: Java 17, Spring Boot 3, Spring Security, JWT, Spring Data JPA, SQL, Redis, H2, Flyway, Docker, GitHub Actions
- **Key Highlights**:
  * Layered architecture with **40+ RESTful APIs** across auth, booking, payment, and notification modules, documented with OpenAPI/Swagger, Bean Validation, and global exception handling.
  * **JWT auth** (access/refresh tokens), **RBAC for 3 roles**, BCrypt hashing, login rate limiting, and account lockout.
  * **JPA optimistic locking** for concurrent bookings and **idempotent payment APIs** (idempotency keys) to prevent duplicate transactions on retries.
  * Versioned **Flyway** migrations, pagination, indexing, and **Redis cache-aside** with database fallback.
  * **79 automated tests** (JUnit 5, MockMvc, Spring Boot Test) on an H2 in-memory DB, with GitHub Actions CI and Docker for consistent environments.
